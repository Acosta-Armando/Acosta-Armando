Soy un **Desarrollador Fullstack** apasionado por construir soluciones web escalables y aplicaciones móviles de alto rendimiento. - 📍 **Ubicación:** Valencia, Carabobo, Venezuela.
- 🤖 **AI-Driven Development:** Potencio mi flujo de trabajo mano a mano con la inteligencia artificial utilizando **Cursor AI** para optimizar el desarrollo, refactorización y resolución de problemas complejos.
